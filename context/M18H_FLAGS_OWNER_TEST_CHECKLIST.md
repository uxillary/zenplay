# M18H Flags owner phone check

Allow about 10–15 minutes. Use the latest release on a real phone. No developer tools are needed.

## Before you start

- [ ] Open ZenPlay while online and open **Flags**.
- [ ] Check that the screen fits and you can read the choices without sideways scrolling.

## Try the three modes

- [ ] **Classic:** answer a few questions. Try one right and one wrong answer. Read the feedback and open **Did you know?** when it appears. Check that the next button is easy to tap.
- [ ] **Practice:** miss one answer on purpose. Check that its flag returns later and that the learning tip is easy to read.
- [ ] **Reverse:** answer a few questions. Check that all four flags are visible and keep their shapes.
- [ ] Change to a region and check that a new round starts for that region.
- [ ] Rotate the phone if convenient. Increase text size if your phone offers that setting. Check for cut-off text or controls.

## Try offline

- [ ] While online, leave ZenPlay open briefly so it can finish loading.
- [ ] Turn on airplane mode (or disconnect Wi-Fi and mobile data), then reload or reopen ZenPlay.
- [ ] Open Flags, answer a Classic question, and check that its flag appears. If time allows, check one question in Practice and Reverse too.
- [ ] Return to Home and open Flags again while still offline.
- [ ] Turn airplane mode off when finished.

If anything fails, note the phone model, browser, mode, whether you were online, and what you expected versus what happened. A photo or screenshot helps describe layout issues.
