# Flags owner QA

Allow about 10–15 minutes. Use the latest deployed ZenPlay on your phone and desktop. You do not need special testing tools.

## Phone (about 6 minutes)

- [ ] Open ZenPlay online and confirm **Flags** appears on Home. Start **Classic**.
- [ ] Answer one question correctly and one incorrectly. Check that choices and buttons fit, feedback is clear, and the next-question button appears. Finish the round and try replay.
- [ ] Start **Practice** and deliberately miss a flag. Continue through a few questions and check that the missed flag returns. Finish or stop the session.
- [ ] Start **Reverse**. Check that all four flag cards are visible, recognisable, and keep their shapes. Try a different region and start a round.
- [ ] Check portrait and landscape if practical. Watch for clipped text, overlapping controls, or sideways scrolling.

## Desktop (about 4 minutes)

- [ ] Use Tab, Shift+Tab, Enter, and Space to navigate setup and answer choices. Check that keyboard focus is visible.
- [ ] Complete a round, review results, replay, and use Back to Games. Check browser Back and Forward.
- [ ] Set browser zoom to 200%. Check that text and controls reflow and remain usable. Notice long names such as **Democratic Republic of the Congo**.

## Offline (about 3 minutes)

- [ ] While online, load ZenPlay and open Flags; wait briefly for the app to finish loading.
- [ ] Disconnect Wi-Fi/mobile data (or use airplane mode), then reload/reopen ZenPlay.
- [ ] Open Flags and try a Classic question. If available, also open Reverse and check that flag images appear.
- [ ] Reconnect to the internet afterward.

## What to report if something looks wrong

Please include the device and browser, approximate screen size if known, the mode, what you expected and what happened, and a screenshot when useful. Note whether you were online or offline and the browser zoom level for layout issues.
