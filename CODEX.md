# Codex Working Rules

## Main rule

Use minimal tokens. Do not explain everything unless asked. Make small, safe changes only.

## Before editing

1. Read this file first.
2. Inspect only the files needed for the task.
3. Do not scan the whole repo unless necessary.
4. Ask only if blocked.

## Response style

- Be brief.
- Give the result first.
- No long theory.
- No big option lists.
- No “here are 12 improvements” unless requested.
- Mention only changed files and key reason.

## Coding rules

- Do not rewrite whole files unless necessary.
- Prefer small patches.
- Keep existing style/design.
- Do not change unrelated files.
- Do not generate binaries/images.
- Do not edit lockfiles unless dependencies changed.
- Do not invent features beyond the prompt.

## Workflow

For each task:

1. Restate the exact target in one sentence.
2. Make the smallest useful change.
3. Summarise changed files.
4. Suggest one next step only.

## Token-saving mode

Assume every response should be compact. Avoid repeating context from previous messages.
